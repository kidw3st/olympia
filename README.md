# Локальная копия olympiaperm.ru

Статическая копия сайта СК «Олимпия» (1С-Битрикс), снятая 26.08.2026.

## Как открыть

```bash
node _tools/serve.js 8099
```

Затем открыть <http://127.0.0.1:8099/>.

Локальный сервер нужен потому, что часть страниц лежит по путям вида `/price/` →
`price/index.html`. Открыть `site/index.html` напрямую через `file://` тоже можно,
но часть переходов по каталогам работать не будет.

## Принятые решения

**Счётчики и виджеты не скачивались** (Яндекс.Метрика, Google Analytics, callibri,
botfaqtor) — ссылки на них оставлены абсолютными. Качать их бессмысленно, и копия
не должна слать данные в чужую аналитику.

**Библиотеки с CDN скачаны** в `site/_external/` — иначе копия разваливается без
интернета.

**Мусорные URL отфильтрованы** по `robots.txt`: пагинация `PAGEN`, `print=`,
`login=`, `utm_`, версия для слабовидящих. Без этого краулер уходит в бесконечные
комбинации параметров.

## Что заведомо не работает

Это статическая копия, поэтому серверная логика Битрикса не работает:

- **поиск** (`/search/index.php`) — ссылки на него оставлены абсолютными, ведут на живой сайт;
- **формы** (обратный звонок, запись, подписка) — некуда отправлять;
- **cookie-баннер** — дёргает `POST /bitrix/.../modal_cookie/popup.php`, даёт 404 в консоли;
- **онлайн-оплата и личный кабинет** — разделы `/personal/`, `/auth/` не копировались.

## Полнота копии

Проверено двумя сплошными проходами:

- `node _tools/check-coverage.js` — все **453 из 453** URL из карт сайта есть на диске;
- `node _tools/verify.js` — **0 битых** внутренних ссылок из 161 138.

Пагинации на списках нет, скрытых за `PAGEN` страниц не существует.

## ЧЕК-ЛИСТ ДЛЯ ПЕРЕНОСА: битые ссылки самого оригинала

Всё перечисленное отдаёт **404 на живом сайте** — это мёртвые ссылки в вёрстке,
а не пропуски копии. При переносе их стоит либо починить, либо убрать.

Битрикс отдаёт на них «мягкий 404» (красивую страницу «не найдено» со статусом 404),
поэтому в браузере они выглядят почти работающими и легко проходят мимо глаз.

## Про `/ads/` и `/newyear/`

Изначально пропускались как закрытые в `robots.txt`. Проверено отдельно: оба раздела
и все страницы внутри них отдают 404 — их на сайте нет. Ограничение из
`pageAllowed()` снято, так что при повторном обходе они подхватятся, если появятся.

Докачать отдельные разделы, не перекачивая остальное:

```bash
ONLY_PREFIX=ads,newyear SKIP_EXISTING=1 node _tools/crawl.js
```

Внимание: в Git Bash значение **без ведущего слеша** — иначе оболочка подменит
`/ads/` на `C:/Program Files/Git/ads/`.

# DESIGN.md — «Олимпия», редизайн

Записано с построенного мира (redesign/), а не с намерений. Источник истины —
`redesign/css/style.css`; при расхождении верить CSS.

## Тезис

Главный бассейн города как инженерная спецификация воды: просторно, точно,
без рекламного крика. Структурная дисциплина T1 Energy, перенесённая в живую
палитру «Олимпии». Иерархия — тональными слоями, теней нет вообще.

## Палитра

| Токен | Значение | Роль |
|---|---|---|
| `--ice` | `#edf3f8` | канвас страницы (не чисто белый) |
| `--ice-deep` | `#dde8f0` | утопленный слой на льду |
| `--paper` | `#f7fafc` | приподнятый слой |
| `--navy` | `#103153` | тёмные поверхности: нави-пилюля, лента фактов |
| `--navy-ink` | `#0d2846` | основной текст на льду |
| `--depth` | `#081a2e` | футер, самый глубокий слой |
| `--blue` | `#0b56a6` | фирменный синий: большие поля (детская секция, CTA-полосы) |
| `--blue-bright` | `#1668c0` | ссылки на льду (контраст 4.97:1) |
| `--red` | `#ed4432` | фирменный красный: ТОЛЬКО метки (квадраты ленты, полоса знака) |
| `--action` | `#d43826` | красный действия: заливки кнопок (белый текст 4.78:1) |
| `--action-press` | `#c0341c` | hover кнопок, focus-кольцо |
| `--mist` | `#5a7089` | вторичный текст на льду (4.56:1, из синей гаммы — не серый) |
| `--mist-dark` | `#9db8d2` | вторичный текст на нави |
| `--hairline` / `--hairline-dark` | `#c3d2e0` / `#2a4a70` | волосяные линии |

Правило: `--red` никогда не заливка под текстом; для кнопок только `--action`.

## Типографика

- **Unbounded 300/400** — дисплей (родство с геометрией логотипа: стадионная «О»).
  h1 героя: `clamp(1.6rem, 6.4vw, 4.9rem)`, uppercase, line-height 1.04.
  Заголовки секций: `clamp(1.7rem, 3.9vw, 3rem)`, вес 300 всегда.
- **Onest 400/500/600** — текст, 17px/1.55. Inter/Geist/Space Grotesk запрещены брифом.
- Числа: `font-variant-numeric: tabular-nums` (часы, телефоны, лента).
- Тире в копирайте — минимум; диапазоны часов через короткое тире `–` без пробелов.

## Форма

- Пилюли (кнопки, фильтры): радиус 999px. Нави-пилюля шапки: 22px.
- Фото-порталы: 30px мобайл → 44px десктоп; крупные (hero, kids, CTA-полоса) 72px.
- Волосяные строки-списки: `border-top/bottom 1px --hairline`, текст с вертикальным
  паддингом 18–30px. Это основной список всего сайта (услуги, билеты, документы).
- Квадрат 5×5px `--red` — разделитель ленты фактов и маркер списков на синем.
- Теней НЕТ. Глубина = лёд → paper → navy → depth.

## Движение

- Кривые: `--ease-out: cubic-bezier(0.23,1,0.32,1)`, `--ease-in-out: cubic-bezier(0.77,0,0.175,1)`.
- **Авторский ход: «вода наполняет»** — clip-path `inset(100% 0 0 0)` → 0 снизу вверх,
  800ms ease-in-out, на фото-порталах при входе в вьюпорт (`.reveal-fill`, IO once).
- Текстовые блоки: `.reveal` — opacity+translateY(18px), 600ms ease-out.
- Вход героя: `@starting-style`, каскад задержек 0/70/140/200ms.
- Лента фактов: linear marquee 36s; `prefers-reduced-motion` → статична.
- Аккордеоны: `grid-template-rows 0fr→1fr`, 300–320ms ease-out.
- Кнопки: `:active scale(0.97)` 140ms. Hover — ТОЛЬКО цвет (бриф запрещает hover-анимации).
- Смена фото направлений: crossfade + blur(6px→0), 350ms.
- Каскад списков: карточки одной сетки всплывают друг за другом. Задержку
  считает наблюдатель по пачке, которую отдал за один раз (70ms на шаг,
  потолок 7 шагов), — работает и на трёх карточках, и на ленте из трёхсот.
- Заголовок раздела: линия под h2 дочерчивается scaleX 0→1, 620ms; в фитнесе
  оранжевая.
- Обложки (`.hero-porthole`, `.page-cover`, `.post__cover`, `.dirpage-hero__media`):
  сдвиг ±14px против прокрутки, `scale(1.08)` чтобы края не оголялись.
- Полоса прочитанного в статье: 3px сверху, `scaleX` по доле прокрутки;
  на короткой заметке, которая влезает в экран, скрыта.
- Плитки галереи появляются подбором — translateY(10px) + scale(0.97).
- Полоса действия: две волны разной скорости (26s и 38s навстречу),
  SVG в data-URI, 6–9% белого.
- Числа занятости набегают за 900ms с замедлением к концу.
- Шапка уплотняется после 40px прокрутки (`.is-scrolled`).
- `prefers-reduced-motion`: движение убирается, opacity остаётся.

**Класс `js` ставит инлайн-скрипт в `<head>`** — до первой отрисовки, иначе
анимируемые блоки успевают мигнуть перед тем, как скрыться. Тот же скрипт
через 3,5 секунды ставит `no-motion`, если `main.js` не поднялся: пустого
экрана из-за анимации быть не может.

## Поверхности браузера

`::selection` синий/белый; scrollbar тонкий нави на `--ice-deep`; `:focus-visible`
2px `--action-press` offset 3px; underline-offset 0.22em.

## Компоненты

- **nav-pill** — плавающая sticky-пилюля `--navy`: белый логотип-PNG (оригинал,
  `assets/logo-white.png`, высота 19px), ссылки, телефон, красная CTA, бургер <1080px.
- **ticker** — тёмная лента фактов, дублированный трек, элементы Unbounded 300 15px caps.
- **dir-item / qa-item** — аккордеоны на волосяных строках, кружок-плюс 44px
  (поворот вертикальной черты 90° при открытии).
- **ticket-row** — строка-ссылка: имя Unbounded 300 + подсказка `--mist`, hover синий.
  Для длинных документов (правила, freeze, compare).
- **hub-cards** — сетка 1/2/3 карточек `--paper`, радиус `--r-small`, без тени.
  Хабы (посетители, расписание, направления) и блок билетов на главной.
- **sched-grid** — таблица-пример слотов, метка «пример» как у occupancy;
  на узком экране горизонтальный скролл.
- **row-link** — строка списка новостей: миниатюра 84–108px радиус 14px
  (фолбэк — волновой знак на нави), заголовок, категория.
- **cta-band** — синее поле радиус 44px, заголовок + белые пилюли.
- **team-card** — фото 3/3.6 радиус 14px, имя 600, роль `--mist`.
- **hours/spec-rows** — dl-строки «термин слева, значение справа жирным».
- **footer** — `--depth`, 3 колонки, соцсети в круглых обводках, водяной знак
  «ОЛИМПИЯ» Unbounded 16% на всю ширину.

## Иконки

Только рисованные inline-SVG: stroke 1.75, round caps/joins (rounded-lineal).
Никаких эмодзи, юникод-глифов, Lucide.

## Анти-паттерны (закреплены брифом)

Чисто белый фон, drop shadows, 3 карточки в ряд, 3 тарифа, bento-сетки, градиенты,
неон, эмодзи, kicker/eyebrow над заголовками, section numbers, hover-эффекты
движения, спарклы/орбы/сетки точек, фейковые отзывы, выдуманные цены.

## Сборка

Порядок важен: генераторы пишут страницы, финишные проходы правят готовый HTML.

```bash
node _tools/build-pages.js      # направления, контакты, цены, FAQ, команда, правила
node _tools/build-articles.js   # 352 статьи новостей и акций + списки с фильтрами
node _tools/build-rest.js       # остальные страницы копии по общему шаблону
node _tools/build-special.js    # профили сотрудников и страницы расписаний
node _tools/build-baths.js      # бани и сауны: вкладки с фото и описанием
node _tools/build-docs.js       # 78 документов из копии, разложенных по разделам
node _tools/build-b2b.js        # корпоративным клиентам
node _tools/build-schedule.js   # data/schedule.json — сетка занятий (правится руками)
node _tools/polish-html.js      # размеры картинок, loading, alt, rel=noopener
node _tools/relink.js           # ссылки ведут в редизайн, а не в старую копию
node _tools/restamp.js          # версии css/js во всех страницах (обход кэша)
```

Страницы, которые собираются отдельными скриптами, перечислены в `SKIP_RELS`
внутри `build-rest.js` — иначе общий конвертер их перезапишет.

- `_tools/redesign-lib.js` — каркас, шапка, футер; глубина вложенности — аргумент.
- `_tools/typography.js` — русская типографика и чистка разметки Битрикса.
- `_tools/photo-bank.js` — подбор фотографий из присланного архива по manifest.csv.
- Пересборка безопасна и идемпотентна; правки контента — в этих скриптах,
  правки мира — только в style.css.

## Проверки

```bash
node _tools/verify.js       # целостность всех внутренних ссылок
node _tools/audit.js        # картинки без размеров, пустые alt, дубли id
node _tools/check-news.js   # типографика и остатки вёрстки в статьях
node _tools/check-coverage.js  # все ли URL из карт сайта скопированы
```

`_tools/device-check.js` запускается в браузере (вставкой в консоль): ищет
горизонтальную прокрутку, мелкие цели нажатия, обрезанный текст и битые картинки.
